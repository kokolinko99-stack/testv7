THRTYSIX — QUAINT HF FONT FILE

This patch configures the entire website to use Quaint HF.

Add your licensed font file to this folder and rename it to ONE of these supported filenames:
- QuaintHF.woff2   (recommended)
- QuaintHF.woff
- QuaintHF.ttf
- QuaintHF.otf

Preferred path:
public/fonts/QuaintHF.woff2

Do not rename the folder. After committing the font file to GitHub, Vercel will redeploy automatically.
